# Security

This is VeilCore's registry. Everything in this repository is in scope, and so is the
production registry it deploys. The wider policy (response times, what happens after a
report, the contracts and the website) is in the main repository's
[SECURITY.md](https://github.com/hunterincoming/veilcore/blob/main/SECURITY.md).

- **Preferred:** GitHub private vulnerability reporting (Security tab → "Report a
  vulnerability"), on this repository where that button is offered, or on the
  [main repository](https://github.com/hunterincoming/veilcore/security/advisories/new).
- **Or email:** hunter@veilcore.org, subject starting "SECURITY".

Please don't open a public issue for a vulnerability.
